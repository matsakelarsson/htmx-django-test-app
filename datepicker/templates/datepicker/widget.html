{% comment %} The wrapper is the CSS anchor the calendar positions itself against. The button opens the popover natively (popovertarget) and, on the same click, has htmx load the month that matches whatever the input holds. Picking a day swaps this whole element, which closes the popover. The widget usually sits inside a form that has htmx attributes of its own. hx-disinherit keeps those from leaking in, and every request element below names its own target and swap. {% endcomment %}
